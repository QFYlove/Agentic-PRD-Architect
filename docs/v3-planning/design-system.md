# V3.0 视觉设计规范

- 状态：草案，基于可运行原型 `design-preview/v3/`，待用户确认方向
- 方向：A Swiss Editorial（基础）+ C Tactical Flat Design（表达）
- 实现参考：`design-preview/v3/src/styles/tokens.css`、`base.css`、`shell.css`

## 1. 设计立场

界面像一份排好版的技术出版物，而不是控制台。秩序来自网格、细线和编号；识别度来自少量黑色几何块、朱红强调和等宽字体的技术标记。装饰只出现在不承载信息的位置（工作台刊头、项目封面、空状态），信息区域只用线条和排版组织。

与旧版的区别：

| 旧版（V2） | V3 |
|---|---|
| 深色画布 `#0b0f14`，青色强调 `#2cb7c9` | 纸张白 `#F1F0EB`，朱红强调 `#D9543D` |
| 圆角 6–8px 面板，层层边框 | 直角；用细线分区，不用卡片包裹 |
| 标签页切换所有内容 | 每个阶段一个页面，页面内用网格分区 |
| 状态靠颜色徽章 | 状态靠形状符号，颜色只做辅助 |

## 2. 颜色

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#F1F0EB` | 页面底色 |
| `--sheet` | `#FAFAF7` | 内容面（文档、基线栏、当前轮次） |
| `--sheet-2` | `#F6F5F0` | 备用浅面 |
| `--ink` | `#17191B` | 主要文字、实心几何块、选中填充 |
| `--ink-2` | `#65686A` | 次要文字 |
| `--ink-3` | `#929593` | 弱化文字、编号、元数据 |
| `--rule` | `#C8C9C4` | 普通分隔线 |
| `--rule-soft` | `#DDDCD6` | 列表内细分隔 |
| `--rule-strong` | `#292C2D` | 区块标题线、控件边框 |
| `--accent` | `#D9543D` | 当前位置、主操作悬停、待确认、must_fix、冲突与风险 |
| `--accent-ink` | `#B3402C` | 朱红文字（在浅底上满足对比度） |
| `--accent-wash` | `#F6DFD8` | 关联高亮底色、删除行底色 |
| `--ok` | `#3D6B4F` | 已保存、已采纳（仅文字和小方块） |

规则：
1. 朱红在任一屏中只用于"当前"和"需要你处理"两类信息。大面积朱红只出现在刊头的一个几何方块。
2. 不使用渐变背景、发光、阴影。唯一的渐变用法是线条图案（斜切、虚线条），属于图形而不是氛围。
3. 正文 `--ink` 在 `--sheet` 上约 16:1；`--ink-3` 只用于 11px 以上的元数据，不用于正文。
4. 深色主题不在 MVP 范围；将来需要单独设计（定义 9.3），不得把浅色变量反转。

## 3. 字体

| 用途 | 字体栈 | 说明 |
|---|---|---|
| 中文与英文界面 | `Inter, "IBM Plex Sans", -apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif` | |
| ID、版本、状态、编号 | `"IBM Plex Mono", ui-monospace, "SF Mono", Menlo, Consolas, monospace` | |

**原型没有加载任何网络字体**，实际渲染的是本机已安装字体（macOS 上为 SF / PingFang SC / SF Mono）。Inter 与 IBM Plex 均为 SIL OFL 1.1 许可，可以自托管；是否打包字体文件见 [open-decisions.md](open-decisions.md) D-03（定义 9.5 要求使用前确认许可和运行环境）。

### 字号

| Token | px | 用途 |
|---|---|---|
| `--t-meta` | 11 | ID、时间、等宽元数据 |
| `--t-ui` | 13 | 控件、列表、次要说明 |
| `--t-body` | 15 | 界面正文 |
| PRD 正文 | 16 / 行高 1.75 | 编辑器阅读区 |
| `--t-lead` | 17 | 用户回答、引言 |
| 问题 | 19 | 本轮问题 |
| `--t-h3` | 22 | 区块标题、章节标题 |
| `--t-h2` | 30 | 页面标题 |
| `--t-display` | 44–88（`clamp`） | 工作台刊头 |

规则：页面标题字重 700、字距 -0.02em；刊头 -0.035em、行高 0.95。等宽元数据字距 +0.02～0.12em，英文副标题全大写。中文正文不加字距。

## 4. 网格与间距

- 8px 基准：`--s1`…`--s8` = 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- 页面外边距 `--margin` = `clamp(16px, 3.4vw, 48px)`；栏间距 24px。
- 工作台：12 栏网格，非对称分配（刊头 8 栏 + 统计 4 栏；新建 4 栏 + 项目列表 8 栏）。
- 工作区（探索、编辑器）：固定侧栏 + 弹性主栏 + 固定侧栏，三栏各自独立滚动，顶栏吸顶。
- PRD 正文阅读宽度上限 760px（约 46 个汉字），章节编号放在左侧 56px 装订线中。

## 5. 线条与几何

| 元素 | 规格 | 用途 |
|---|---|---|
| 细线 | 1px `--rule` / `--rule-soft` | 列表行、分组分隔 |
| 强调线 | 1px `--rule-strong` | 区块标题下方、控件边框、栏间分隔 |
| 粗线 | 3px `--ink` | 文档标题下、当前轮次顶部、用户回答左侧 |
| 位置条 | 3–4px `--accent` | 当前阶段、当前章节、当前目录项、关联条目 |
| 编号块 | 实心 `--ink` 方块 + 反白等宽数字 | 区块编号（A / B / C、02、04） |
| 裁切角标 | 10px L 形 2px 黑线 | 强调"输入区"（新建项目） |
| 斜切块 | `clip-path` 多边形 | 刊头、Logo |
| 连接线 | 1px 朱红正交折线 + 两端 6px 方块 | 对话引用 ↔ 基线条目 |
| 追溯链 | 竖向 1px 线 + 9px 空心方块，末端实心朱红 | 需求追溯 |

几何块不放在正文、表格或列表内部。

## 6. 状态与标记

### 需求条目状态（形状编码）

| 状态 | 符号 | 文字颜色 |
|---|---|---|
| 已确认 Confirmed | 实心黑方块 | 主文字 |
| AI 推断 Inferred | 空心方块 + 半块斜切 | 次要文字，状态字朱红 |
| AI 建议 Proposed | 空心方块 + 中心朱红小方块 | 次要文字 |
| 假设 Assumption | 虚线空心方块 | 次要文字、斜体 |
| 待确认 Open | 朱红空心圆 | 主文字 |
| 已拒绝 Rejected | 灰色方框 + 叉 | 删除线、弱化，默认隐藏 |

形状在黑白打印或色弱情况下仍可区分（定义 9.7 E"颜色不能成为唯一区分方式"）。

### 其他标记

| 标记 | 规格 |
|---|---|
| 优先级 P0 / P1 / P2 | 10px 等宽；P0 实心黑底，P1 黑框，P2 灰框 |
| 探索发现 A–E | 20px 方块内字母；B 一致性、D 风险为朱红实心，E 机会为空心，A / C 为黑色实心 |
| 评审严重度 | Finding 记录左侧 4px 竖条：must_fix 朱红实心、should_fix 黑色实心、optional 灰色虚线 |
| 事实标签 | 正文内 10px 等宽小框：用户输入（实线）、假设（虚线 + 斜体）、待确认（朱红框） |
| Finding 锚点 | 正文下划线 2px，must_fix 朱红、其他灰色、optional 点线；右上角小号 ID |
| 章节来源 | 8px 方块：AI 生成空心、AI 定向优化半斜切、人工编辑朱红实心 + 朱红文字 |
| 阶段进度 | 6 段 3–4px 条：已过黑色、当前朱红、未到浅灰 |
| 版本差异 | 符号列 `+` / `−` + 左侧 3px 竖条（新增黑、删除朱红）+ 删除线 + 修改原因标签 |

## 7. 组件

| 组件 | 规格 |
|---|---|
| 主按钮 | 40px 高，黑底白字，直角；悬停变朱红，箭头右移 3px |
| 线框按钮 | 1px 黑框透明底；悬停反白 |
| 文字操作 `.act` | 无边框；悬停出现 1px 黑框；"确认 / 采纳"加粗 |
| 分段控件 | 1px 黑框，选中项黑底白字；可带朱红计数 |
| 输入框 | 无边框，纸色底，底部 1px 黑线；聚焦时白底、底线变朱红 |
| 区块标题 | 编号块 + 中文标题 + 英文等宽副标题 + 底部强调线 |
| 列表行 | 上下细线，悬停顶部 2px 黑线从左展开，选中为朱红 |
| 侧栏面板 | 与主区用 1px 强调线分隔，内部不再套边框 |
| 提示条 Toast | 黑底白字，左侧 4px 朱红，底部居中 |
| 空状态 | 40px 方框内一条对角线 + 一句说明 |

不使用的组件：圆角卡片、阴影浮层、徽章胶囊、图标按钮组、图表仪表盘。

## 8. 动效

| 动效 | 时长 | 用途 |
|---|---|---|
| 页面进入 | 220ms，上移 6px + 淡入 | 页面切换、展开详情 |
| 线条展开 | 220ms，`scaleX` 从左 | 当前阶段、当前章节、列表行悬停 |
| 连接线绘制 | 260ms，描边动画 | 对话 ↔ 基线关联 |
| 新写入下划线 | 700ms | 本轮写入基线的条目 |
| 扫描线 | 900ms 循环 | 本轮处理中（唯一的循环动画，处理完成即停止） |

缓动统一 `cubic-bezier(0.2, 0.7, 0.2, 1)`。`prefers-reduced-motion` 下所有时长置 0。

## 9. 响应式断点

| 宽度 | 工作台 | 需求探索 | PRD 编辑器 |
|---|---|---|---|
| ≥1440 | 刊头 + 统计；新建 + 项目列表 + 活动 | 进度栏 168px + 对话 + 基线 | 目录 232 + 正文 + 面板 380 |
| 1280–1439 | 同上，栏宽收紧 | 同上 | 目录 208 + 面板 340，版本只显示编号 |
| 1024–1279 | 项目列表通栏；新建与活动并排 | 进度栏收为 64px 图标列 | 目录改为抽屉，由"目录"按钮打开 |
| <1024 | 单列 | 对话 / 基线两个标签切换；阶段导航移到底部 | 单栏；问题面板改为覆盖层，默认收起 |
| <600 | 统计改三列横排；项目行两行布局 | 问题全宽、提交按钮全宽 | 章节编号移到标题上方 |

## 10. 无障碍

- 所有可点击元素是 `button` 或 `a`；状态符号带 `aria-label` 和 `<title>`。
- 键盘焦点统一 2px 朱红描边。
- 分段控件使用 `role="tab"` / `radio` 和 `aria-selected` / `aria-checked`。
- 连接线、封面图形、刊头图形 `aria-hidden`。
- 原型尚未做完整的键盘流程和读屏测试，正式开发时需要补充。

## 11. 禁止项检查

定义 9.8 的 12 条禁止项在原型中的情况：深色圆角卡片、霓虹强调、渐变背景、玻璃拟态、发光边框、阴影、星光 / 机器人装饰、图表堆砌——均未使用。"嵌套容器"控制在一层（基线栏内的"AI 发现"框是唯一的边框容器）。"三列窄卡片"——评审改为单列记录。"仅换颜色保留旧信息架构"——页面结构按项目和阶段重新组织。
