# 差旅报销 PRD

## 1. 背景

员工出差后的报销目前走纸质流程，平均 3 周到账。本次改为线上流程。

## 2. 流程

1. 员工提交报销单，上传电子发票。系统调用税务平台接口校验发票真伪（假设公司已开通该接口，待财务确认）。
2. 部门经理审批。
3. 金额较大的报销需要更高层级审批。
4. 财务复核。
5. 财务打款。

## 3. 约束冲突与决策

财务要求所有报销单由财务人工复核，业务部门要求 1000 元以下的报销自动通过、当天到账，两者不能同时满足。

- 方案 A（推荐）：1000 元以下先自动打款，财务次日抽查 20%，发现问题从下次报销中扣回。代价：放弃"所有报销单人工复核"，改为事后抽查。
- 方案 B：全部人工复核，财务承诺小额报销 1 个工作日内复核完毕。代价：放弃"当天到账"。

需要财务负责人与业务部门负责人共同确认。

## 4. 时效

报销单提交后 30 天内必须完成打款。超过 25 天仍未打款的，系统提醒财务负责人。经确认，到账目标为提交后 3 个工作日。

## 5. 验收标准

- 上传非电子发票时提示"仅支持电子发票"。
- 经理驳回后，员工可以修改后重新提交。
- 报销单在第 25 天未打款时，财务负责人收到提醒。
